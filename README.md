# Song of the Eared Robot English Cover
A shell script to run the music video of my cover of Song of the Eared Robot by 耳ロボP (MimiroboP) using translated lyrics by Moonlit Star, using the "techo" program also by 耳ロボP (MimiroboP)
## Dependencies
- [techo](https://github.com/nwp8861/techo), installed to PATH with the filename changed to "techo", instead of "techo.py". For instructions on how to install techo, please refer to the [techo installation instructions](https://github.com/nwp8861/techo#install)
- [mpv](https://mpv.io/)
